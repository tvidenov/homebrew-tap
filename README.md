# Homebrew tap for AgentDock

```
brew install --cask tvidenov/tap/agentdock
```

AgentDock keeps your coding agents (Claude Code, Codex and more) on the edge of your Mac's screen, with one Inbox
for their questions. https://www.agentdockapp.com

The cask installs the latest signed and notarized DMG from
[AgentDock-releases](https://github.com/tvidenov/AgentDock-releases); the app updates itself afterwards.
